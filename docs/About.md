# About Me


## About the developer

I'm a recently retired career technologist and software engineer who focused mostly on backend projects, such as
APIs, data processing and system integrations.

I also enjoy gaming, especially indie games with action / puzzle / RPG mechanics so Tunic was right up my ally!
My wife and I played it together, but quickly realized it would be tedious to 
solve the language translation just using pencil and paper.  I also was looking for an excuse to learn Vue or other
frontend frameworks, and so the Tunic Language Tool was born!

## Wait, is this that vibecoded AI slop I've heard so much about?!

No!  

Absolutely not!

...

Mostly.

I created the Tunic Language Tool as a way of expanding my personal frontend development knowledge and because,
as a retired career techie, I love building stuff!

That said, I did use free LLM support (Gemini and ChatGPT) to learn about and produce small snippets of code, in much
the same way I formerly would have done normal searches for answers on places like Stack Overflow.

I also leveraged a bit of free LLM time on some tiresome aspects of the TipTap customizations integrating my
hand-designed Tunic language Vector graphics (plus inline translations).

So, mostly hand written code and this was a fun & educational project for me!
