# Issues

## Known issues

1. Deleting entire rune vs single character  
In the document editor, if the cursor is adjacent to a rune word (on either side), delete or backspace will
delete the entire rune word rather than a single character.  
A workaround is to use the arrow keys.  Pressing the relevant arrow key to move the cursor towards the rune word will 
first make the cursor visibly shorter, at which point delete or backspace will only remove a single rune character
rather than the whole word.
